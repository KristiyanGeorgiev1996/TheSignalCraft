# Documentation

This directory contains the extended project documentation for **TheSignalCraft**.

The purpose of this documentation is to provide a clearer technical overview of the system beyond the main repository README. While the main README focuses on project presentation, this folder explains the internal structure, processing flow, configuration model, testing approach, and current limitations in more detail.

## Contents

- `architecture.md`  
  Describes the overall project architecture and responsibility separation.

- `workflow.md`  
  Explains how a signal moves through the system from input to final decision.

- `modules.md`  
  Provides a detailed explanation of each core module in the project.

- `testing.md`  
  Documents the automated test coverage and testing philosophy.

- `configuration.md`  
  Explains environment configuration and setup requirements.

- `limitations.md`  
  Outlines the current system limitations and future improvement areas.

## Goal

The documentation is intended to make the project easier to understand, maintain, extend, and review from an engineering perspective.
