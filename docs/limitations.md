# Limitations

## Overview

TheSignalCraft is a practical signal evaluation system, but like any rule-based analytical tool, it has important limitations.

Understanding these limitations is essential for using the system responsibly and evaluating its current capabilities accurately.

---

## Current Limitations

### 1. No Trade Execution

The system does not execute trades automatically.

It is designed strictly as a decision-support tool.

---

### 2. No Profit Guarantee

The system does not guarantee successful outcomes or profitability.

All outputs should be treated as analytical guidance, not financial advice.

---

### 3. Heuristic Probability Model

The probability estimation is heuristic.

It is based on historical analog logic and rule-based conditions rather than a trained machine learning model.

---

### 4. External Data Dependency

The system depends on external market data sources.

If the data is delayed, incomplete, or unavailable, the analysis quality may be affected.

---

### 5. Rule-Based Scoring Constraints

The scoring system is rule-based and relies on predefined conditions.

While transparent and interpretable, it is not adaptive like machine learning models.

---

### 6. Limited Input Format

The system expects a strict input format.

This improves reliability but limits flexibility for different signal styles.

---

### 7. Limited Interface Scope

The current implementation is focused on Telegram interaction.

There is no web interface, API layer, or standalone UI at this stage.

---

## Why These Limitations Matter

Documenting limitations is important because it:

- improves transparency  
- prevents overpromising  
- sets realistic expectations  
- highlights areas for future improvement  

---

## Future Improvements

Potential future improvements include:

- expanding supported input formats  
- improving output clarity and reporting  
- adding richer analytics  
- extending test coverage  
- improving configuration management  
- introducing alternative interfaces (CLI, web dashboard)  
- exploring advanced statistical or ML-based models  

---

## Summary

TheSignalCraft should be understood as a modular analytical tool for signal evaluation.

It is not an automated trading system and should not be treated as a predictive or guaranteed-profit solution.
